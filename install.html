Upgrading an existing instance

On a server that already runs bytEM, keep .env and run ./install.sh. It pulls the new images and restarts the stack.

Re-run env_setup.sh only to change the domain or administrator. It keeps every secret already in .env, backs the old file up, and needs --force when .env exists.
