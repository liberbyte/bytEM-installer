Upgrading an existing instance

The same command upgrades a server that already runs bytEM. It finds the folder the running stack was started from, else ~/bytEM, and keeps its .env, certificates and volumes.

  • An installer folder is updated with git pull, and install.sh pulls the published images.
  • A checkout of the bytEM source is updated with git pull and its submodules, then rebuilt with docker compose up -d --build --force-recreate.
  • A folder whose .env names another deployment domain is left alone, and the command stops.

For an installer folder. Volumes are kept.

On the server, env_setup.sh --force changes the domain or administrator of an installer folder. It keeps every secret already in .env and backs the old file up.

    01 Install from your computer

    Copy it, paste it into Windows PowerShell or a Linux terminal and press Enter. It fetches remote_install.sh from the installer repository and runs it on the server: Docker and git when missing, then the install or upgrade. The wizard's values travel base64-encoded in the last word.
